The honest fine print.

A small tracker should be clear about what it can and cannot do.

What if my phone has no step-counter sensor?

You can still enter steps manually, log workouts and use the run timer. Live run steps and cadence show an em dash instead of fabricated values.

Does Running include distance, pace or calories?

No. Running records a timer, sensor steps when available and rolling cadence. Motionfit does not request location access or calculate routes, distance, pace or calorie expenditure.

Will automatic steps work in the background?

When the sensor, activity access, notifications and foreground service are available, automatic tracking can run in the background. Battery policies or a force-stop may interrupt it. Motionfit reports “App-open only” or “Unavailable” rather than claiming tracking is active when it is not.

Where is my data stored?

In a local SQLite database on your phone. There is no account or cloud backup. Settings includes a confirmed action to clear all Motionfit data.

Is Motionfit on Google Play?

Not yet. The download here is the existing version 2.0.0 debug APK for Android 8.0 or newer. Android will ask you to allow installation from your browser or file manager before installing it.
